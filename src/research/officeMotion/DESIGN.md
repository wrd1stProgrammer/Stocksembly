# Approved office motion in production

Visual contract: native world 1374×1145; invariant actor scale 0.60. Reuse source sprites read-only, native pixel compositing and side-profile clothing/arm repairs. Warm dimensional desks, four directional chair layers, wall-mounted translated signs, lowered personal desks and four team meeting tables remain intact.

Production adapter: authoritative research snapshots select destinations and conversation roles. Only visual movement/gestures interpolate in the renderer; they must not advance research or manufacture events, evidence totals or conclusions. Live speech comes from existing projected events and waits for visible arrival. The same renderer serves home ambient snapshots and live/focused research subsets.

Preserve app shell and existing UI/camera controls: overview, focus, free drag/pinch/wheel, actor detail selection. Reduced motion uses static poses at semantic destinations; pause and document hiding stop visual time. Cleanup releases RAF, observers and listeners. Room language is an instance input, not a module global or URL side effect. Keep existing accessible status text and expose selectable actors to keyboard users.

Verification is deliberately focused per user request: adapter boundary tests, TypeScript/build and actual browser interaction on home/live research. No new packages, image generation, deployment or broad performance/SEO audits.
