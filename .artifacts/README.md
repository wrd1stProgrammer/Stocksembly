# Local investigation output

All files beneath this directory except this README are Git-ignored and excluded from Docker builds. Use it for temporary logs and captures, not source or the only copy of important data.

Curated, sanitized results belong in [docs/audits](../docs/audits/), with the command, commit, input context and limitations. Keep raw production data and credentials outside the repository.

The previously committed `quality-gates/` experiment logs were archived before removal. See [the cleanup record](../docs/repository-cleanup.md) for recovery. Ignoring a path does not delete existing local files; inspect them before local cleanup.
