# 10개 리서치 실사용 평가

2026-09-07 KST, 운영 서비스의 로그인된 브라우저에서 다른 종목 10개를 전부 Pro·전체 위원회·영문으로 요청했다. 실패한 표본을 성공한 질문으로 교체하지 않았다. 운영 기준 버전은 `ac7ae2c`이며 이번 실패 수정 코드는 아직 배포하지 않았다.

10개 모두 최종 상태를 확인했다. 운영 최초 발행은 TSLA 한 개(제한 사항 포함), 나머지 아홉 개는 미발행이다. 실패를 제외한 내용 평균은4.25/10, 미발행을0점으로 포함한 전체 요청 전달 가치 평균은0.425/10(표시0.43)이다. 최초 발행률10%와 로컬 복구 결과를 혼합하지 않는다.

## TSLA: 4.25점

직접 답변0.75, 사실·출처1.75, 분석0.5, 반론0.5, 최신성0.5, 표현0.25.

전체 보고서를 브라우저에서 읽고 다크 차트 화면을 확인했다. 329배 TTM PER, 178배 예상 PER과 로보택시 수익 공개 필요성은 관련성이 있다. 그러나 자동차 부문의 정상 이익·가치 범위·시가총액 중 비중이 없어 “얼마나”라는 질문에는 답하지 못했다.

약43.52B달러의 현금·단기투자는 공시와 일치한다. 현금흐름 카드의5.8B는 TTM인데, 최근 분기 음수 FCF와 기간 설명 없이 함께 나온다. 4개 팀이 모두 기권하면서 첫 판단은 Balanced, 가치평가 유형은 Cash-generating compounder로 표시돼 의미가 어긋난다. 분석가 목표가와 매수 의견 수는 로보택시 사업 경제성에 대한 강한 반증이 아니다. [Tesla Q2 10-Q](https://www.sec.gov/Archives/edgar/data/1318605/000162828026049270/tsla-20260630.htm)

## 실제 실패 수정과 검증 범위

| 원인 | 운영 실패 종목 | 수정 및 확인 |
|---|---|---|
| V3 요약에 구형360자 제한 적용 | GOOGL, PLTR, COIN, JPM, XOM | 기존 V3의4,000자 계약과 일치시켰다. 동일한 저장 입력으로 모두 로컬 발행 확인. 주장·출처 연결 검사는 유지. |
| 검증에 전달된 원문 창에서 재무표 누락 | MSFT | 숫자·표 헤더·기간 맥락과 수정된 주장에 맞게 원문 범위를 선택. 실제 모델 재감사 후 로컬 발행 확인. 이전 감사 결과는 덮어쓰지 않음. |
| 미등록 비율 문장의 반복 거부 | AMD, COST | 수정 재시도 후에도 남은 해당 문장만 생략하고 제한 사항 표시. 남을 내용이 없으면 계속 거부. 실제 실패 출력 검증; AMD는 전체 로컬 발행, COST는 실패 메모 경계만 확인. |
| 선택적 추가 조사의 형식 오류가 전체 실패로 전파 | LLY | 선택적 `output_invalid`만 기존 생략 경로로 처리. 필수 응답·권한 오류는 유지. 오류 경로 회귀 검증 및 실제 모델로 로컬 발행 확인. |
| 생성한 감사 제한 문구의 소수 자릿수·문장 ID 충돌 | COIN 로컬 복구 중 추가 발견 | 기존 표시 반올림 규칙 적용, 결정/섹션 ID 분리. 원본 감사 근거와 판정 보존 후 동일 입력 발행 확인. |

관련 신규 경계 검증과 워커 TypeScript 검사, 실제 서비스 재생을 수행했다. 후속 조사 테스트의 기존 예산 기대값2개는 수정 전 기준에서도 실패함을 확인했고 그대로 남겼다. 전체 테스트가 모두 통과했다고 주장하지 않는다. 상세한 재현과 한계는 [실행 기록](ten-research-evaluation-plan.md)에 있다.

MSFT처럼 이미 저장된 감사에서 핵심 근거가 빠진 실패는 발행 버튼만 다시 눌러도 같은 감사가 재사용된다. 새 입력으로 감사 단계부터 다시 실행해야 한다. 이번에는 이를 로컬 복사본에서 검증했으며 운영 실패 상태를 직접 수정하지 않았다.
