- 양쪽 사이드바가 모두 열리면 차트 카드가 좁아진다. 개별 확대 및 패널 접기를 제공한다. 밀도가 높아도 모든 작도를 한 번에 읽어야 하는 문제는 후속 디자인 개선 여지다.

## 구현 중 발견해 고친 문제

1. 모델 strict JSON wire 스키마의 optional 필드 때문에 실제 specialist 호출 실패: 선택 해설을 nullable required 문자열로 분리. 저장된 이전 메모는 그대로 읽는다.
2. June의 입력 예산을 공시와 요청 원장이 먼저 차지해 차트가 누락: 시장 캔들 근거 우선, 요청 원장은 분석 인라인에서 제외, 차트 요약 축소.
3. 한국어만 포함한 정상 해설과 여러 작도 참조가 거절됨: 언어별 유효한 해설만 적용하고 실제 작도 예산인 7개까지 참조 허용.
4. 아주 오래된 먼 주봉 지지가 선정됨: 최근 스윙과 현재 가격/ATR 거리 중심으로 선정 수정.
5. 차트 조회가 부모 애니메이션 갱신에 반응: 안정적인 원시 식별자 의존성으로 변경하고 회귀 테스트 추가.
6. 차트 페이지 추가 뒤 후속 챕터 번호 중복: 선택 차트 챕터를 포함해 번호 조정.

차트 저장·해설·조회·PDF는 선택적 보강 경로다. 선택 차트 실패를 기존 보고서의 발행 실패 조건으로 추가하지 않았다. June의 기존 전문 조사 호출을 사용하며 별도 모델 회의나 재시도 단계를 추가하지 않았다.

## 남은 품질 개선 우선순위

1. 팀의 구조화 판단 라벨과 본문 투자 행동 의미 일치. 대기를 신규 진입 긍정으로 바꾸는 경로를 정리한다.
2. 재무 수치 재계산을 모델 자유 산술 대신 단위가 있는 결정적 계산 결과에 연결한다. 잘못된 재계산을 근거 불일치로 승격하지 않는다.
3. 종합 보고서가 한 대표 주장만 반복하지 않도록 가격에 반영된 기대, 핵심 반론, 행동 전환 조건을 함께 요약한다.
4. 감사 입력의 source alias와 실제 차트 근거 연결을 개선한다. 차트가 있는데 실업률/CPI 출처로 판정하는 기존 문제가 관찰됐다.
5. 장중 마지막 봉은 1시간 대신 30분, 4시간 대신 2.5시간일 수 있다. 현 거래량 비율은 직전 20봉 대비이며 같은 시간대·길이로 보정한 비율은 아니다. 정규장 시간대별 거래량 비교를 후속 개선하고 이를 단독 매매 신호로 쓰지 않는다.
