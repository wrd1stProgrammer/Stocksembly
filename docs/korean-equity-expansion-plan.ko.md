# Stocksembly 한국 주식 확장 조사 및 준비안

작성일: 2026-07-31
범위: 현재 미국 주식 전체위원회 리서치 파이프라인을 한국 상장주식까지 확장하기 위한 데이터·로직·제품 준비

## 1. 결론

한국 주식 지원은 가능하다. 처음부터 별도의 리서치 엔진을 만들 필요도 없다.

가장 현실적인 1차 조합은 다음과 같다.

1. **현재 유료 InsightSentry**
   - 종목 검색
   - 현재가와 등락률
   - 시간·일봉
   - 기술지표
   - 펀더멘털과 일부 컨센서스
   - 뉴스
   - 실적발표 자료 및 콜 문서
2. **무료 OpenDART**
   - 기업 식별
   - 사업·분기·반기보고서
   - 연결·별도 재무제표
   - 공시 원문
   - 최대주주·임원·대량보유
   - 유상증자, CB·BW, 합병, 분할, 자기주식 등 주요 사건
3. **무료 한국은행 ECOS·KOSIS**
   - 기준금리, 국고채 금리, 환율, 물가, GDP, 산업 통계
4. **금융위원회 공공데이터**
   - D+1 일별 주가의 보조·복구 경로

그러나 다음 데이터는 무료 API만으로 상업용 SaaS에 안정적으로 제공하기 어렵다.

- 실시간 KRX 시세의 제3자 재배포
- 외국인·기관·개인 순매수
- 공매도·대차·프로그램 매매
- 지수 구성종목과 비중의 상업적 사용
- 신뢰도 높은 국내 증권사 컨센서스
- 한국어 유료 뉴스 원문

따라서 **InsightSentry + OpenDART + ECOS는 기능 검증용 베타에는 충분하지만, 유료 리서치 제품에는 충분하지 않다.** 유료 제품으로 공개하려면 최소한 국내 컨센서스 또는 자체 추정치, 외국인·기관 수급, 공매도·대차·신용잔고, 기업행사, 조정주가의 안정적인 원천을 추가해야 한다. 이 공백의 상당수는 한국투자증권 KIS Open API가 기술적으로 제공하지만, Stocksembly가 사용할 수 있는지는 개인 키 발급이 아니라 제휴 자격과 KRX·코스콤 정보이용계약을 먼저 확인해야 한다.

## 2. 현재 Stocksembly가 한국 주식을 거부하는 이유

현재 구조는 데이터 공급자가 한국 종목을 못 주기 때문이 아니라 애플리케이션 계약 자체가 미국 전용이기 때문이다.

### 코드에 들어 있는 미국 전용 가정

- 종목 검색 요청이 `country=US`로 고정됨
- 국가가 `US`가 아니면 검색 결과를 폐기함
- 통화가 `USD`가 아니면 검색 결과를 폐기함
- 거래소 타입이 `NASDAQ | NYSE | NYSE_AMERICAN`으로 한정됨
- 기업 식별자가 SEC `CIK` 10자리라고 가정함
- 공식 공시 원천이 SEC라고 가정함
- 거시 원천이 미국 재무부와 BLS라고 가정함
- 실적 캘린더 요청도 `country=US`로 고정됨
- 유료 데이터의 권리 검증도 미국 거래소와 CIK가 있어야 통과함

이 때문에 InsightSentry가 `KRX:005930`을 반환해도 현재 `normalizeSymbol()` 단계에서 제거된다.

### 유지할 수 있는 것

다음 핵심 구조는 국가와 무관하므로 그대로 유지할 수 있다.

- 실행 생성과 작업 대기열
- 원본·정규화 데이터의 CAS 저장
- 기준시각과 Snapshot 봉인
- 11명 전문 에이전트
- 4개 팀 통합
- 교차 반론
- 후속 조사와 책임자 응답
- 구조 감사와 의미 감사
- 의장 합성과 원자적 발행
- 이전 리서치 대비 변화
- 예상 Q&A

즉, 리서치 토론 엔진을 복제하지 않고 **시장별 데이터 어댑터와 분석 정책을 주입**하는 구조로 바꾸는 것이 맞다.

## 3. 현재 유료 InsightSentry 실측

2026-07-31 현재 Stocksembly에 설정된 기존 구독 키로 삼성전자 `KRX:005930`을 소량 호출했다. 인증키와 응답 원문은 출력하거나 저장하지 않았다.

| 기능 | 결과 | 실측 내용 |
|---|---|---|
| 한국 종목 검색 | 지원 | `country=KR` 검색에서 50개 결과 |
| 삼성전자 식별 | 지원 | `KRX:005930`, `KRW`, `STOCK` |
| 기업정보 | 지원 | HTTP 200, 거래소·통화·산업 등 반환 |
| 현재가 | 지원 | HTTP 200, 가격과 등락 데이터 반환 |
| 일봉 | 지원 | HTTP 200, 요청한 5개 bar 반환 |
| 펀더멘털 | 지원 | HTTP 200, 858개 indicator 반환 |
| 뉴스 | 지원 | HTTP 200, 테스트 구간 10건 반환 |
| 문서 | 지원 | HTTP 200, 인덱스 150건 반환 |
| 실적 캘린더 | 불완전 | HTTP 200이지만 삼성전자 결과 0건 |

### 해석

현재 유료 API는 한국 주식의 시장·재무 데이터 기반으로 사용할 수 있다. 다만 다음 확인이 더 필요하다.

- 858개 펀더멘털 중 실제로 채워진 핵심 지표의 비율
- 연결·별도 재무제표가 혼합되지 않는지
- 분기 값과 누적 값이 올바르게 구분되는지
- 컨센서스와 목표주가가 어느 종목까지 제공되는지
- 뉴스가 한국 현지 이슈를 충분히 포착하는지
- 문서의 언어·종류·시점 정확성
- 한국 데이터의 최종 사용자 표시·재배포 권리가 현재 RapidAPI 구독에 포함되는지

마지막 항목은 기술 문제가 아니라 계약 문제다. API 호출 가능 여부와 유료 SaaS 화면에 재표시할 권리는 다를 수 있으므로 공급자 약관 또는 서면 확인이 필요하다.

## 4. 무료 공식 데이터 조사

### 4.1 OpenDART: 한국판 SEC의 핵심 원천

OpenDART는 1차 구현의 필수 데이터다.

### 가져올 수 있는 데이터

- 8자리 `corp_code`, 6자리 `stock_code`, 회사명
- 기업개황, 대표자, 업종, 홈페이지, 결산월
- 공시 목록과 접수번호
- 공시 원문 ZIP/XML
- 사업보고서, 반기보고서, 1·3분기보고서
- 연결재무제표 `CFS`
- 별도재무제표 `OFS`
- 재무제표 전체 계정과 XBRL
- 주요 재무지표
- 최대주주 현황
- 임원·주요주주 소유보고
- 5% 이상 대량보유 상황보고
- 소액주주 현황
- 유상·무상증자
- 전환사채·신주인수권부사채
- 합병·분할·영업양수도
- 자기주식 취득·처분
- 감사의견과 보수

OpenDART는 원칙적으로 무료이며 일반적인 요청 제한 초과 코드는 약 20,000건 이상에서 발생한다고 안내한다. 기업용 신청에서는 회사·서비스·요청 IP를 등록하게 된다.

### 미국 데이터와의 대응

| 미국 원천 | 한국 대응 |
|---|---|
| SEC company ticker + CIK | DART `corpCode.xml`의 `corp_code + stock_code` |
| 10-K | 사업보고서 |
| 10-Q | 1분기·반기·3분기보고서 |
| 8-K | 주요사항보고서·수시공시 |
| Company Facts | OpenDART 전체 재무제표·XBRL |
| Forms 3·4·5 | 임원·주요주주 소유보고 |
| Schedule 13D·13G | 대량보유 상황보고 |
| 13F | 정확한 무료 대응 없음 |

### 주의점

- 정정공시가 제출되면 과거 수치가 바뀔 수 있다.
- 공시 접수시각 기준의 point-in-time 보존이 필요하다.
- `CFS`를 기본으로 사용하되 `OFS`도 별도 보관해야 한다.
- 분기 손익은 3개월 값과 누적 값이 함께 존재하므로 혼동하면 안 된다.
- 회사별 사용자 정의 XBRL 계정명이 많아 표준 계정 매핑이 필요하다.
- DART가 제공하는 값은 제출 회사 책임이며 감독원이 정확성과 완전성을 보장하지 않는다.

공식 자료:

- [OpenDART API 목록](https://opendart.fss.or.kr/intro/infoApiList.do)
- [고유번호 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019018)
- [기업개황 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019002)
- [단일회사 전체 재무제표 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019020)
- [공시 원문 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019003)
- [OpenDART 이용약관](https://opendart.fss.or.kr/intro/terms.do)

### 4.2 금융위원회 주식시세정보: 무료 D+1 가격

공공데이터포털의 금융위원회 주식시세정보는 종목 코드와 날짜별로 시가·고가·저가·종가·거래량·거래대금을 제공한다.

- 비용: 무료
- 개발·운영 승인: 자동승인
- 기본 개발 트래픽: 10,000건
- 라이선스 표기: 이용허락범위 제한 없음
- 실제 갱신: 영업일 다음 날 오후 1시 이후

따라서 현재가 표시에는 늦지만 다음 용도로 유용하다.

- InsightSentry 장애 시 전일 종가 복구
- 장기 일봉 교차 검증
- 가격 조정 전후 이상치 탐지
- 저비용 백필

[금융위원회 주식시세정보](https://www.data.go.kr/data/15094808/openapi.do)

### 4.3 한국은행 ECOS: 한국판 Treasury·BLS 대체

ECOS는 무료 JSON/XML API로 다음 데이터를 제공한다.

- 한국은행 기준금리
- 국고채 금리와 회사채 금리
- 원/달러 등 환율
- 소비자물가
- 생산자물가
- GDP·GNI
- 통화량과 신용
- 산업별 기업경영분석

현재 미국 파이프라인의 Treasury 수익률곡선과 BLS CPI·실업률을 그대로 한국 분석에 넣으면 안 된다. 한국 주식의 할인율과 경기 환경은 최소한 다음으로 교체해야 한다.

- 한국 기준금리
- 국고채 3년·10년
- 회사채 AA- 스프레드
- USD/KRW
- 한국 CPI
- 한국 GDP 또는 산업생산

[한국은행 ECOS 연계 안내](https://www.data.go.kr/data/15059629/openapi.do)

### 4.4 KOSIS: 산업 수요를 보강하는 무료 통계

KOSIS는 국가 통계표를 JSON·XML·SDMX 등으로 제공한다. 출처표기를 지키면 상업적 이용과 재배포도 가능하다고 공식 FAQ에서 안내한다.

활용 예:

- 자동차 등록·수출
- 반도체 생산·수출
- 소매판매
- 건설·부동산
- 인구와 가구
- 고용
- 업종별 생산·재고

모든 회사에 같은 통계를 넣지 말고 업종별 데이터 맵을 두어야 한다.

- [KOSIS OpenAPI](https://kosis.kr/openapi/index/index.jsp)
- [KOSIS 상업 이용 안내](https://kosis.kr/openapi/community/community_0401List.do)

### 4.5 한국수출입은행 환율

ECOS 환율 장애 시 보조 원천으로 사용할 수 있다.

- 무료
- 이용허락범위 제한 없음
- 신규 도메인 `oapi.koreaexim.go.kr` 사용 필요

[한국수출입은행 환율 API](https://www.data.go.kr/data/3068846/openapi.do)

## 5. 무료지만 상업용 서비스에 바로 쓰면 안 되는 데이터

### 5.1 KRX Open API

KRX Open API는 2010년 이후의 종목 기본정보와 일별 매매정보, 지수, 파생상품 등을 제공한다. 하지만 공식 약관은 API 결과를 **비상업적 목적으로만 사용**하고 제3자에게 대가를 청구하지 못하도록 규정한다.

Stocksembly는 유료 리서치 SaaS이므로 무료 KRX Open API를 핵심 데이터로 사용하면 안 된다.

실시간 또는 지연 시세를 재배포하는 수익사업은 별도 계약이 필요하며, KRX는 코스콤을 통한 승인·계약 절차를 안내한다.

- [KRX Open API 서비스 목록](https://openapi.krx.co.kr/contents/OPP/INFO/service/OPPINFO004.cmd)
- [KRX Open API 이용약관](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp)
- [KRX 시세 데이터 계약 안내](https://openapi.krx.co.kr/contents/OPP/DATA/OPPDATA003.jsp)

### 5.2 한국투자증권 KIS Open API

KIS는 단순 주문 API가 아니다. 국내 주식 리서치에 부족했던 데이터 상당수를 한 곳에서 제공한다.

#### 기술적으로 가져올 수 있는 데이터

- 현재가, 체결, 호가, 예상체결
- 일·주·월·년 봉과 장중 분봉
- 시간외 가격·체결
- 종목 기본정보와 상품정보
- 재무상태표, 손익계산서
- 수익성·안정성·성장성 등 재무비율
- 추정실적
- KIS 종목 투자의견과 증권사별 투자의견
- 외국인·기관 순매수 집계와 종목별 투자자 동향
- 프로그램 매매
- 공매도 일별 추이
- 대차거래 일별 추이
- 신용잔고 일별 추이
- 시장자금
- 배당, 합병·분할, 감자, 상장, 공모, 유·무상증자, 주주총회, 보호예수 등 예탁결제원 일정
- 시가총액·재무비율·배당수익률·공매도·신용잔고 등 순위
- 업종지수와 시장 요약
- 실시간 체결·호가·프로그램 매매 WebSocket

즉 데이터 기능만 보면 KIS는 Stocksembly의 **시장팀과 재무팀을 크게 강화할 수 있는 후보**다.

#### 그러나 개인용 키를 서비스에 넣으면 안 된다

한국투자증권 공식 안내상 개인 고객과 일반 법인은 본인 또는 자기 법인의 자산을 위한 용도로 Open API를 사용할 수 있다. Stocksembly처럼 API 데이터를 가공해 제3자 사용자에게 제공하려면 제휴 절차가 필요하다.

더 중요한 제약은 다음과 같다.

- 공식 제휴 안내는 제도권 금융회사를 주요 대상으로 명시한다.
- 투자일임업·투자자문업 등이 아닌 일반 핀테크사는 제휴가 불가하다는 예시가 있다.
- 제휴 API를 받더라도 시세정보를 화면에 표시하려면 KRX·코스콤과 별도의 시장정보 이용계약이 필요하다.
- 개인 또는 일반 법인 키로 가격·수급 데이터를 Stocksembly 사용자에게 재제공하는 방식은 허용된 사용으로 볼 수 없다.

그러므로 KIS는 기본 전제로 채택할 데이터 원천이 아니라 **제휴 가능 여부를 먼저 확인할 조건부 원천**이다. “주문 기능 없이 리서치 데이터만 제공하는 SaaS”라는 서비스 구조를 한국투자증권 제휴 담당자에게 전달하고 서면 답변을 받아야 한다. 공식 안내 문구만 보면 일반 핀테크 서비스의 승인 가능성은 낮으므로, 동시에 코스콤·FnGuide·DataGuide 등 상업용 데이터 계약 경로도 비교해야 한다.

#### 제휴가 가능할 경우의 취득 순서

1. 한국투자증권에 회사 소개와 API 이용계획을 제출한다.
2. 서비스 가입 정보, 사업자등록증, 법인인감증명서, 서버 IP와 고정 개발 IP를 준비한다.
3. 법인 명의 대표계좌와 HTS ID 등 요구사항을 충족한다.
4. 제휴용 App Key·App Secret·제휴사 번호를 발급받는다.
5. KRX·코스콤 시장정보 이용계약과 화면 표시 범위를 별도로 확정한다.
6. 계약서에 현재가, 과거가, 수급, 공매도, 대차, 컨센서스의 저장·가공·최종 사용자 표시 권리를 항목별로 기록한다.

- [KIS 국내주식 API 목록](https://apiportal.koreainvestment.com/apiservice-category)
- [KIS Open API 일반 안내](https://apiportal.koreainvestment.com/apiservice)
- [KIS 제휴 대상 및 데이터 사용 조건](https://apiportal.koreainvestment.com/provider-info)
- [KIS 제휴 절차](https://apiportal.koreainvestment.com/provider-process)
- [KIS 공식 예제 저장소](https://github.com/koreainvestment/open-trading-api)

### 5.3 배당·발행정보 등 일부 예탁결제원 계열 공공 API

공공데이터포털에 무료로 공개되어 있어도 라이선스가 공공누리 제2유형이면 상업적 이용이 금지된다. 예를 들어 금융위원회 주식배당정보는 상업적 이용 시 한국예탁결제원과 별도 정보이용계약이 필요하다고 명시한다.

따라서 API가 무료인지뿐 아니라 **각 데이터셋의 이용허락범위**를 개별적으로 저장하고 검사해야 한다.

[금융위원회 주식배당정보](https://www.data.go.kr/data/15043284/openapi.do)

## 6. 미국 주식과 한국 주식 분석의 핵심 차이

### 6.1 종목 식별

미국은 티커와 CIK 중심이지만 한국은 다음을 함께 관리해야 한다.

- 6자리 종목코드
- DART 8자리 `corp_code`
- KRX 시장: KOSPI·KOSDAQ·KONEX
- 공급자 코드: 예 `KRX:005930`
- ISIN
- 보통주·우선주·종류주
- 상장 법인과 공시 법인의 관계

삼성전자 보통주 `005930`과 우선주 `005935`는 같은 기업 공시를 공유하지만 가격·유동성·배당수익률은 다르다. `ticker → company`를 1:1로 가정하면 안 된다.

### 6.2 회계

한국 상장사는 K-IFRS를 사용한다. IFRS 기반이라 미국 GAAP과 큰 틀은 유사하지만 그대로 같은 계정으로 취급하면 안 된다.

- 연결 `CFS`와 별도 `OFS`가 모두 공시됨
- 회사별 XBRL 확장 계정이 많음
- 분기 손익의 단일분기 값과 누적 값 구분 필요
- 억원·백만원·원 단위 혼합 가능
- 영업이익 표시와 일부 국내 추가 공시 요구가 존재
- 금융업은 일반 제조업과 다른 재무 템플릿 필요
- 정정 보고서가 흔하므로 최신값과 당시값을 모두 보존해야 함

한국 상장사는 연결·별도 재무보고를 전자 제출하며 일반적으로 연차보고서는 결산 후 90일, 분기보고서는 분기 후 45일 이내 제출 구조다.

- [IFRS Foundation 한국 적용 현황](https://www.ifrs.org/use-around-the-world/use-of-ifrs-standards-by-jurisdiction/view-jurisdiction/south-korea/)
- [한국 전자보고 요건](https://www.ifrs.org/content/dam/ifrs/publications/jurisdictions/filing-profiles/korea-18-november-2015.pdf)

### 6.3 시장 구조

한국 주식은 다음 특성을 분석에 반영해야 한다.

- 원화 가격과 USD/KRW 민감도
- 장중 가격제한폭 ±30%
- KOSPI와 KOSDAQ의 서로 다른 유동성·위험 특성
- 외국인·기관·개인 수급의 높은 중요도
- 관리종목·투자주의·거래정지·상장폐지 위험
- 유상증자, CB·BW 등 희석성 자금조달
- 지주회사 할인과 계열사 가치
- 보통주·우선주 가격 차이
- 대주주·특수관계인 지배력
- 자기주식과 소각 정책

KRX는 정규장 09:00~15:30, T+2 결제, 일일 가격제한폭 ±30%를 안내한다.

[KRX 한국 주식시장 거래 가이드](https://global.krx.co.kr/contents/GLB/01/0109/0109000000/guide_to_trading_in_the_korean_stock_market.pdf)

### 6.4 지배구조

미국 보고서의 단순 기관보유·내부자 거래 관점만으로는 부족하다.

한국 기업팀과 리스크팀은 다음을 별도 점검해야 한다.

- 최대주주와 특수관계인 지분
- 지배회사·자회사·관계회사
- 내부거래와 일감 의존
- 순환출자 또는 복잡한 지배구조
- 승계 가능성
- 합병비율과 주주가치 이전
- 자기주식의 보유·처분·소각
- 이사회 독립성과 감사의견
- CB·BW·스톡옵션 잠재 희석

## 7. 팀별 리서치 로직 변경

### 7.1 시장팀

추가할 입력:

- KOSPI·KOSDAQ 및 업종 지수
- 한국 기준금리·국고채·회사채
- USD/KRW
- 수출·산업생산 등 업종 통계
- 가능하면 외국인·기관·개인 수급
- 가능하면 공매도·대차

핵심 질문:

- 주가 상승이 실적 개선인지 수급인지
- 원화 강세·약세가 이 회사의 이익에 어떤 방향으로 작용하는지
- 한국 시장·동종업계 대비 상대강도가 어떤지
- 상하한가·거래정지 등 시장제도 위험이 있는지

### 7.2 기업팀

추가할 입력:

- 사업보고서 사업의 내용
- 부문별·지역별 매출
- 주요 고객과 매입처
- 계열사 및 관계회사
- 최대주주·특수관계인
- 주요 계약과 수주
- IR 자료와 공시 정정

핵심 질문:

- 그룹 내부 의존을 제거해도 경쟁력이 유지되는지
- 지배주주와 일반주주의 이해관계가 일치하는지
- 회사가 말하는 성장과 실제 수주·가동률·CAPEX가 일치하는지

### 7.3 재무팀

추가 규칙:

- `CFS` 우선, `OFS` 보조
- 단일분기와 누적 수치 분리
- 모든 값은 원 단위 canonical number로 정규화
- 금융업·보험업·증권업 전용 계정 맵
- 지배주주순이익과 전체 순이익 구분
- 보통주 기준 주당지표 계산

추가 가치평가:

- 배당수익률
- 순현금 또는 순차입금

## 9. 다시 정의한 필수 데이터셋과 취득 방법

아래의 “필수”는 데이터가 한 칸이라도 비면 리서치를 중단하라는 의미가 아니다. 해당 데이터가 없을 때 그 팀이 강한 결론을 내리면 안 된다는 의미다.

### 9.1 출시 전 반드시 확보할 기반 데이터

| 데이터셋 | 필요한 세부 항목 | 우선 취득 방법 | 대체·보조 | 용도 |
|---|---|---|---|---|
| 종목 마스터 | 종목코드, 시장, ISIN, 보통주·우선주, 상장상태, DART 법인코드 | OpenDART `corpCode.xml` + 계약된 시세 공급자 마스터 | KIS 종목 마스터(제휴 시) | 동명이인·주식종류·시장 오인식 방지 |
| 공식 공시 | 공시 목록, 원문, 정정 이력, 접수시각, 주요사항보고서 | OpenDART 기업용 키 | 회사 IR | 모든 사실 판단의 기준 원천 |
| 공식 재무제표 | CFS/OFS, 단일분기·누적, 계정 ID, 단위, 감사 여부 | OpenDART XBRL·전체 재무제표 | InsightSentry, KIS | 실적·현금흐름·재무위험 |
| 가격·거래량 | 현재가, 전일대비, OHLCV, 거래대금, 수정주가 | InsightSentry 표시권 확인 | 금융위 D+1; KIS는 제휴·시장정보 계약 시 | 가치평가 기준일과 기술·유동성 분석 |
| 기업행사 | 배당락, 액면분할, 증자, 감자, 합병, CB·BW, 거래정지 | OpenDART 주요사항보고서 | KIS 예탁결제원 일정(제휴 시) | 수정주가·희석·이벤트 위험 |
| 금리·환율·거시 | 기준금리, 국고채, 회사채, USD/KRW, CPI, GDP, 산업생산 | ECOS API 키 | KOSIS, 수출입은행 | 할인율·경기·환율 민감도 |
| 회사 IR·일정 | 실적 발표, IR 자료, 주총, 가이던스 | 회사 IR + DART 공시 | InsightSentry 문서 | 촉매와 다음 확인일 |
| 뉴스·이벤트 | 국내 규제, 공급망, 수주, 사고, 산업 정책 | InsightSentry의 한국 커버리지 감사 | DART 수시공시; 향후 뉴스 계약 | 공시 밖의 최신 사건 |

#### 무료 API 신청 경로

- **OpenDART:** 기업용 인증키를 신청하고 회사·서비스 URL·요청 IP를 등록한다. 공시와 재무제표의 기준 원천으로 사용한다.
- **ECOS:** 한국은행 ECOS 회원가입 후 API 인증키를 발급받고 통계코드를 고정 관리한다.
- **KOSIS:** OpenAPI 인증키를 발급받아 업종별 통계표 ID를 매핑한다.
- **공공데이터포털:** 금융위원회 주식시세정보 활용신청 후 D+1 OHLCV를 장애복구와 검산에 사용한다.
- **회사 IR:** 회사별 IR 주소를 종목 마스터에 등록하고 문서 수집·중복 제거·공시시각 보존 규칙을 둔다.

### 9.2 돈을 받는 제품이라면 추가해야 할 차별화 데이터

| 데이터셋 | 가장 현실적인 취득 방법 | 무료 대안 | 없을 때 생기는 품질 저하 |
|---|---|---|---|
| 국내 컨센서스 | InsightSentry 커버리지 확인 또는 FnGuide·DataGuide·KIS 제휴 | 사실상 안정적 대안 없음; 자체 시나리오 추정 | 목표가·예상 EPS·실적 서프라이즈 방향이 약해짐 |
| 외국인·기관·개인 수급 | KIS 제휴+시장정보 계약, 코스콤 또는 국내 벤더 | 상업 SaaS용 안정적 무료 원천 없음 | 한국 주가의 단기 동인을 설명하기 어려움 |
| 공매도·대차 | KIS 제휴+시장정보 계약, KRX·코스콤·벤더 | 공개 웹 자료는 재배포·자동화 권리 불명확 | 하방 압력과 숏커버 가능성 판단이 약해짐 |
| 신용잔고·프로그램 매매 | KIS 제휴 또는 시장데이터 벤더 | 안정적 무료 원천 없음 | 개인 레버리지와 기계적 수급 위험 누락 |
| 업종지수·구성종목·비중 | KRX·코스콤 또는 허가된 벤더 | 자체 피어 바스켓 | 정확한 벤치마크·상대강도·패시브 수급 분석 제한 |
| 한국어 뉴스·콜·인터뷰 | 뉴스 공급자 또는 콘텐츠 계약 | 회사 IR·DART만 사용 | 경영진 톤 변화와 비공시 산업 신호 부족 |
| 산업별 KPI | KOSIS·정부기관 + 업종별 협회/계약 데이터 | 업종에 따라 일부 무료 | 반도체 가격, 조선 수주, 바이오 임상 등 사업 방향성이 약함 |
| 지분·지배구조 그래프 | OpenDART 원문을 자체 정규화 | 가능하지만 개발비 큼 | 지주사 할인·승계·관계사 리스크 설명이 피상적 |

### 9.3 자체 계산해야 하는 데이터

공급자가 계산한 숫자를 그대로 보여주는 것만으로는 차별화가 약하다. 다음은 Stocksembly가 원천 데이터에서 직접 계산하고 계산식·기준시각을 저장해야 한다.

- TTM과 단일분기 성장률
- 순현금·순차입금과 EV
- 희석주식수와 완전희석 EPS
- PER·PBR·EV/EBITDA·FCF yield
- 과거 밴드와 국내·글로벌 피어 대비 프리미엄
- 보통주·우선주 괴리율
- 지주회사 NAV 할인
- 외국인·기관 수급 강도와 거래대금 대비 비중
- 공매도·대차·신용잔고의 표준화 점수
- 환율·금리·원자재 민감도
- 정정공시·자금조달·희석 위험 점수
- Bull/Base/Bear 시나리오와 결론이 뒤집히는 임계값

이 자체 계산층이 있어야 공급자를 바꿔도 리포트의 논리와 화면이 유지된다.

|---|---|---|

## 12. 최종 권고

지금 당장 KRX·코스콤의 고가 실시간 데이터 계약부터 할 필요는 없다.

먼저 다음 범위로 **비공개 베타**를 만드는 것이 비용 대비 가장 좋다.

1. InsightSentry의 한국 주식 시장·펀더멘털 기능 활성화
2. OpenDART를 공식 공시와 재무 수치의 기준 원천으로 추가
3. ECOS로 한국 금리·환율·거시 환경 추가
4. 금융위원회 D+1 가격을 장애 복구용으로 추가
5. 가격·공시·재무에서 자체 계산한 한국형 valuation board 추가
6. 컨센서스가 없으면 목표가를 흉내 내지 말고 Bull/Base/Bear 임계값으로 대체
7. 수급·공매도는 “현재 미제공”으로 명확히 표시
8. 30개 대표 종목 커버리지 감사 후 지원 종목만 베타에 열기

동시에 한국투자증권에 다음을 문의한다.

- 비금융 리서치 SaaS가 데이터 전용 제휴 대상이 될 수 있는가
- 현재가·과거가·수급·공매도·대차·신용·컨센서스를 최종 사용자에게 표시할 수 있는가
- 필요한 KRX·코스콤 계약과 비용 항목은 무엇인가
- 데이터 저장, 파생지표 계산, 리포트·PDF 표시가 허용되는가

KIS 제휴가 불가능하거나 조건이 맞지 않으면 동일 항목을 코스콤·FnGuide·DataGuide 등 상업용 공급자에게 견적 요청한다.

### 데이터가 이 정도면 충분한가

최종 판단은 다음과 같다.

- **기술 데모:** 충분하다. InsightSentry만으로도 검색·가격·일봉·펀더멘털·뉴스가 동작한다.
- **비공개 펀더멘털 베타:** 충분하다. InsightSentry + OpenDART + ECOS/KOSIS + 금융위 D+1이면 공시 기반 기업·재무·리스크 리서치를 검증할 수 있다.
- **유료 공개 제품:** 아직 부족하다. 컨센서스 또는 자체 추정모델, 수급, 공매도·대차·신용, 안정적인 기업행사·수정주가, 한국 현지 뉴스, 업종별 KPI 중 적어도 해당 종목에 중요한 항목을 확보해야 한다.
- **기관급 제품:** 부족하다. point-in-time 컨센서스, 전체 시장 마스터, 지수 구성과 비중, 고품질 뉴스·콜 원문, 데이터 SLA, 장기 수정주가, 재배포 권리와 감사 가능한 계보가 필요하다.

따라서 “한국 종목 검색이 되고 리포트가 생성된다”를 출시 기준으로 삼으면 안 된다. Stocksembly의 유료 가치 기준은 다음과 같아야 한다.

1. **기업팀:** DART와 IR에서 사업 변화·수주·지배구조를 구체적으로 찾아낸다.
2. **재무팀:** 공식 재무와 현재 가격으로 기대치·밸류에이션·하방 여지를 직접 계산한다.
3. **시장팀:** 업종·환율·금리뿐 아니라 수급과 포지셔닝까지 설명한다.
4. **리스크팀:** 희석·정정공시·지분담보·거래정지·감사의견을 구조적으로 경보한다.
5. **최종 위원회:** 네 팀의 수치가 결론을 어떻게 바꾸는지 Bull/Base/Bear 임계값으로 제시한다.

현재 무료·기존 유료 조합은 1·2·4번의 기반을 만들 수 있지만 3번이 약하고, 미래 추정치가 없는 종목에서는 2·5번도 제한된다. 그러므로 **베타 개발과 데이터 계약 조사를 병행하되, 수급·컨센서스 권리를 확보하기 전에는 유료 한국 주식 기능을 완성됐다고 판단하지 않는 것**이 맞다.
