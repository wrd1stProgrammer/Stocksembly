# Office V8 이미지 생성 기록

생성 방식: OpenAI 이미지 생성, 기존 Office V7 캐릭터와 실제 오피스 스크린샷을 시각 참조로 사용. 모든 결과물은 단색 크로마 배경으로 생성한 뒤 알파 채널 PNG로 변환했다.

## 캐릭터 파일럿

- 마야(시장 분석 대표): 4×4, 행은 정면/좌/우/후면, 열은 idle/walk A/walk B/seated-work. 기존 비율을 유지하면서 청록색 리서치 태블릿과 데이터 브로치를 정체성 모티프로 부여했다.
- 리서치 의장: 동일한 4×4 규격. 백발과 버건디 롱 베스트, 금색 포인트의 의사결정 노트를 핵심 모티프로 부여했다.

## 전체 캐릭터 확장

- 준: 테이프 리더, 전기 블루 차트 태블릿
- 알렉스: 베타 지도사, 앰버 비교 자·데이터 슬레이트
- 이든: 모트 헌터, 딥 틸 경쟁우위 지도
- 아리아: 프로덕트 스카우트, 샌드·코랄 제품 보드
- 레오: 워룸 전략가, 러스트 경쟁 지도
- 노아: 포렌식 회계사, 네이비 감사 원장
- 소피아: 가격 설계자, 아이보리 가치 저울
- 하나: 공시 탐정, 차콜·세이지 형광펜 공시
- 리암: 레드팀, 옥스블러드 경고 방패
- 민: 시나리오 워처, 플럼 분기 타임라인

전 캐릭터 공통 프롬프트 계약: 기존 캐릭터의 성별 표현·피부색·머리색·실루엣을 유지하고, 정확히 4열×4행으로 생성한다. 행은 정면/좌/우/후면, 열은 idle/walk A/walk B/seated-work 순서다.

## 엔티티 파일럿

- 분석 의자: 정면/후면 2종을 한 시트로 생성. 어두운 네이비 패브릭, 얇은 청록 파이핑, 회전형 베이스를 사용했다.
- 증거 포럼: 252×174 비율의 낮은 타원형 바닥 인레이. 아이보리 테두리, 슬레이트 블루 면, 청록·앰버 데이터 아크를 사용했다. 충돌 영역이 없는 완전 보행 가능 엔티티다.

공통 제약: 텍스트·로고·사람(엔티티 시트)·배경 소품·외곽 그림자 금지, 기존 오피스의 소프트 픽셀아트와 동일한 탑다운 시점 유지.
