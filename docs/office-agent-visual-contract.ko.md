# Stocksembly 에이전트 시각 계약 v1

이 문서는 리서치 오피스의 캐릭터와 애니메이션을 다시 제작할 때 지켜야 할 런타임 계약이다. 새 캐릭터는 실존 투자자의 얼굴을 복제하지 않고 투자 철학을 오리지널 인물의 실루엣, 소품, 색상과 동작으로 표현한다.

## 제작 순서

1. 마야와 박 의장의 턴어라운드를 먼저 확정한다.
2. 두 캐릭터로 걷기, 착석, 앉은 대화, 발표를 검증한다.
3. 같은 비율과 광원으로 나머지 열 명을 확장한다.
4. 런타임용 아틀라스는 `atlas.png`, `atlas.json`, `portrait.png`, `profile.json` 네 파일로 납품한다.

## 공통 외형 규칙

- 얼굴보다 실루엣, 헤어스타일, 대표 소품과 자세로 구별되어야 한다.
- 모든 인물을 같은 정장과 같은 체형으로 만들지 않는다.
- 오피스 배경과 동일한 부드러운 픽셀 일러스트 질감과 좌상단 광원을 사용한다.
- 발 피벗, 앉은 엉덩이 피벗, 손의 입력 위치를 전 프레임에서 고정한다.
- 걷기 네 방향은 동일한 키와 체적을 유지한다.

## 필수 클립

- 전 캐릭터: `idle`, `walk`, `turn`, `sit-down`, `stand-up`, `seated-work`, `seated-talk`, `seated-listen`, `talk`, `listen`
- 대표와 의장: `present`, `react`
- 의장: 종합 장면에서 `present`를 확장한 전용 동작 사용

프레임 수, FPS, 지원 방향은 `officeAgentVisualContract.ts`를 단일 기준으로 삼는다.

## 캐릭터 구분 원칙

- 시장 팀: 탐색, 속도, 비교 도구
- 기업 팀: 제품, 경쟁 지도, 장기 전략
- 재무 팀: 장부, 공시, 가격 범위
- 리스크 팀: 방어, 경고, 분기 시나리오
- 의장: 근거 기록철과 절제된 권위

각 캐릭터의 코드네임과 모티프는 코드의 `OFFICE_AGENT_PERSONAS`와 일치해야 한다.
