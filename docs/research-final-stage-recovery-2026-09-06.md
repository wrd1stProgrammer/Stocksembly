## 확인된 원인

캡처와 일치하는 `551c0df8-4b29-4263-b2bd-ad7b5db6144b`는 의미 감사가 성공한 뒤 chair 결과를 4회 거절하고 `chair_synthesis_output_invalid_after_retry`, `chair_synthesis:replacement_exhausted`로 종료됐다.

`projectChairV3ForCommit`은 실제 모델의 본문과 별개로 저장용 구조의 요약을 원문에서 다시 만든다. 이 실행의 핵심 원문은 486자이지만 `validChairCandidate`는 360자 제한을 적용한다. 원문 자체를 다시 넣는 복구도 같은 제한에 걸려 `{}`가 반환된다. 이후 검사가 객체 여부만 확인하므로 `{ canonicalNarrativeV3 }`만 있는 잘못된 저장 결과가 만들어진다. 4번의 정상 모델 응답 모두 같은 코드 경로에서 거절됐다. 이는 새 모델 호출로 해결할 수 없는 결정적 오류다.

숫자 표기에서도 자체 충돌이 있었다. 원문 EPS `$11.995`를 JavaScript `toFixed(2)`가 `$11.99`로 표시하지만 근거 검사는 `$12`를 기대해 거절했다. 표시와 근거 검증에 같은 십진수 반올림(`ROUND_HALF_UP`)을 적용하고, 단위 배율 계산도 십진수로 처리한다. 원시 근거 값은 변경하지 않는다.

다른 2개 실패 실행(`f6e517f4-109c-4d20-82ae-b1cc2fd6371e`, `53b312f3-50c6-42d3-987d-e9b16d2caf0c`)은 이전 형식의 모델 응답이다. 최신 코드의 기존 fallback으로는 각각 복구되므로, 이번 변경의 회귀 대조군으로 사용한다.

## 구현 계획과 완료 기준

1. 완료: 일반 모델 요약의 360자 목표와 원문 보존 경로를 구분했다. 같은 근거 문장의 원문과 정확히 일치하고 기존 언어·수치·4,000자 상한 검사를 통과할 때만 긴 요약을 허용한다. 문장의 조건과 반론을 임의로 자르지 않는다.
2. 완료: 표시·검증·단위 변환의 숫자 처리를 십진수로 통일했다. 양수/음수 중간값 및 배율이 있는 숫자의 반올림을 확인했다.
3. 완료: v3 projection은 최종 저장 스키마를 통과한 결과만 반환한다. 빈 객체는 commit 재시도 전에 발견되어 기존 복구 경로로 전달된다. 출처·권한·fence 검사를 유지한다.
4. 완료: 영어/한국어의 긴 근거, 변형된 문장, 지원되지 않는 숫자, 언어 불일치, 최종 길이 상한을 검사했다. 실제 SQLite chair 경로에서 잘못된 모델 출력도 기존의 긴 근거와 조건을 보존해 한 번의 chair 호출로 저장하는 회귀 테스트를 추가했다.
5. 완료: 관련 테스트 37개와 TypeScript 검사, 변경 파일 lint를 통과했다. 두 회귀 테스트 파일을 CI의 기존 research contract 검사에 포함했다. 최종 변경으로 3개 운영 실패 입력의 12개 응답을 재생해 12개 모두 전체 저장 스키마에 통과하는 것을 확인했다.
6. PR 반영: 검증된 수정만 커밋·푸시하고, CI 결과는 PR의 체크 상태로 확인한다. 운영 반영과 기존 실행 재개 여부는 별도로 명시한다.

## 검증 및 운영 상태

- 실패 캡처의 실행: 수정 전에는 4개 정상 모델 응답 모두 `canonicalNarrativeV3`만 남아 스키마 검증 실패. 수정 후 동일 응답의 전체 저장 구조가 유효하다.
- 나머지 과거 실패 2개의 8개 응답은 기존 fallback과 호환된다. 총 12개 저장 응답 재생은 새 실시간 리서치 12건의 성공률을 뜻하지 않는다.
- `chairSynthesisTextValidation.test.ts`, `chairSynthesisV3.test.ts`: 37개 통과. 두 언어의 SQLite 저장 시나리오 포함.
- `pnpm typecheck`, 변경 파일 lint, `git diff --check`: 통과. Lint의 기존 경고 2개는 변경하지 않았다.
- 운영 DB와 파일은 읽기 전용으로만 접근했다. 모델 재호출, 운영 배포, 기존 실패 실행의 재개는 아직 수행하지 않았다.
- 기존 작업 공간의 변경 사항과 검증용 운영 원본은 커밋에서 제외한다.
