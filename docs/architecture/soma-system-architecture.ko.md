# Stocksembly 시스템 구성 설명

Stocksembly는 사용자가 입력한 미국 주식 종목과 투자 질문을 하나의 LLM 호출로 처리하지 않는다. 웹/API와 장시간 실행 워커를 분리하고, 공식·라이선스 데이터를 먼저 수집해 기준시점을 봉인한 뒤 4개 분석팀의 독립 조사와 교차 검증을 거쳐 출처가 연결된 리포트를 발행한다.

## 구성 요소

### 웹 프론트엔드 및 API

Next.js 기반 웹은 종목·질문 입력, 관심종목 관리, 에이전트 활동 대시보드, 리포트·PDF·예상 Q&A와 브리핑룸 열람을 제공한다. API는 Cognito JWT와 사용자 소유권을 검증하고 실행 명령을 등록한다. 진행 상황은 내구성 있는 Snapshot과 순서가 보장된 SSE 이벤트로 브라우저에 전달되며, 웹 요청 안에서 장시간 데이터 수집이나 모델 실행을 직접 수행하지 않는다.

### 리서치 워커와 멀티에이전트 워크플로

별도의 장기 실행 Node 워커가 SQS에서 리서치 실행을 받아 처리한다. 먼저 SEC·거시·시장 데이터를 수집하고 근거의 기준시점을 봉인한다. 이후 전문 에이전트 11명을 시장 3명, 기업 3명, 재무 3명, 리스크 2명의 4개 팀으로 편성해 독립 메모를 생성한다. 각 팀은 합의안을 만들고 다른 팀의 핵심 주장에 블라인드 반론을 제기한다. 중요한 반론은 최대 3건까지 추가 조사하며, 담당 팀의 답변·투표와 구조·의미 감사를 통과한 주장만 박 의장의 최종 리포트 합성에 사용한다.

### AI 실행과 외부 데이터

OpenAI 모델은 정해진 JSON Schema에 맞춰 분석 결과를 생성한다. 각 실행은 실행 ID, 입력·프롬프트·스키마 해시와 도구 사용 기록을 남겨 결과를 추적할 수 있다. 근거 데이터는 SEC EDGAR와 XBRL Company Facts, BLS, U.S. Treasury, InsightSentry의 시세·기술지표·펀더멘털·뉴스·문서·일정·피어 데이터에서 수집한다.

### 저장 계층

저장소는 하나의 데이터베이스로 합쳐져 있지 않고 역할별로 분리돼 있다. Amazon RDS for PostgreSQL은 사용자·이용권·사용량, 실행과 리포트 소유권·공개 상태, 관심종목·브리핑·읽음 상태를 저장한다. SQLite WAL은 리서치 내부의 작업·시도·이벤트·임대와 재시작 복구를 담당한다. 원시 근거, 정규화 데이터, 에이전트 산출물과 최종 리포트는 SHA-256 콘텐츠 주소형 저장소에 보관되고, 운영 환경에서는 비공개 버전 S3 버킷에 미러링된다.

### 구독 브리핑 워커

브리핑 워커는 미국 거래일과 휴장일을 계산해 미 동부시간 오전 8시 30분, 즉 정규장 개장 1시간 전에 실행된다. PostgreSQL의 활성 관심종목을 종목·언어별로 묶고, 직전 브리핑과 과거 사건 키를 이용해 중복 사건을 제거한 뒤 최신 시세·뉴스·실적·기술 데이터를 수집한다. OpenAI 모델이 한국어·영어 브리핑을 합성하면 출처 Snapshot, 브리핑 본문, 사용자별 delivery와 읽음 상태를 PostgreSQL에 저장해 브리핑룸에 제공한다. 현재 코드에는 브라우저 또는 기기 푸시 알림 발송 기능은 포함되어 있지 않다.

## 제출용 요약 문구

- **웹 프론트엔드·API:** 리서치 요청과 관심종목을 접수하고 Cognito 인증·소유권을 검증한다. Snapshot과 SSE를 이용해 에이전트 활동을 실시간으로 보여주며, 출처가 연결된 리포트·PDF·예상 Q&A와 브리핑을 제공한다.
- **멀티에이전트 리서치 워커:** 전문 에이전트 11명을 시장·기업·재무·리스크 4개 팀으로 편성한다. 독립 분석, 팀 합의, 블라인드 교차 반론, 선택적 후속 조사, 팀 투표와 이중 감사를 거쳐 박 의장이 최종 결론을 편집한다.
- **AI·데이터 계층:** OpenAI 모델이 Schema 기반 분석을 수행한다. SEC 공시·XBRL, BLS·미 국채, InsightSentry의 시세·기술·펀더멘털·뉴스·문서·일정·피어 데이터를 근거로 사용한다.
- **영속성 계층:** PostgreSQL은 사용자·구독·소유권·브리핑을, SQLite WAL은 내부 워크플로 상태를, SHA-256 CAS와 S3는 근거와 리포트 산출물을 저장한다.
- **구독 브리핑 워커:** 미국 거래일 08:30 ET에 관심종목별 신규 신호를 수집·중복 제거하고 한국어·영어 브리핑을 생성해 브리핑룸 delivery와 읽음 상태로 제공한다.
